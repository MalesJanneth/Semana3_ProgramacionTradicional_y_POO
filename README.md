En este proyecto se desarrollo en Pytho, el mismo que permite gestionar dos programas, aplicando la programación tradicional y la programación orientada a objetos con el fin de registrar y mostrar la informaión básica de una mascota, incluyendo: nombre, especie y edad.

**Programación Tradicional:**
En este programa se utiliza el enfoque tradicional, basado en funciones y variables. Se slicita la información de la mascota por teclado para que despues sea mostrado en pantalla al ejecutar el programa de manera organizada.

**Programación Orientada a Objetos (POO):**
Este utiliza el paradima de POO, se crea una clase llamada Mascota, la cual contiene atributos: nombre, especie y edad, asimismo métodos para mostrar información y jecutar acciones. En el archivo main.py se crean objetos representados por mascota1 y mascota2.

**Reflexión:**
La programación tradicional se basa en el uso de fucniones y variables separadas. Este tipo de programación es muy util para programas pequeños, sin emabrgo la aplicación de la POO permite tener mayor orden y escalabilidad cuando se trata de proyectos mucho más extensos ya que se usa clases y objetos. Este paradigma permite la reutilización, el mantenimiento y la comprensión de los códigos.
